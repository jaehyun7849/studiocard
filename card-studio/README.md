# 짤·카드 스튜디오

설치나 로그인 없이 PNG/JPEG 이미지와 문구를 합성하는 정적 웹 편집기입니다.

## 실행

`dist` 폴더에서 정적 HTTP 서버를 실행하세요. 예: `python -m http.server 8000 --directory dist`

별도 빌드, API 키, 서버 데이터베이스가 필요 없습니다. 소스는 `dist/index.html`, `dist/style.css`, `dist/app.js`입니다. 현대적인 Chromium 브라우저를 권장합니다.

## 기능과 정책

- PNG/JPEG의 실제 파일 시그니처와 디코딩을 검사합니다. 최대 10MB, 2,000만 픽셀입니다. 가져온 이미지는 긴 변 최대 2560px로 정규화하며 원본 EXIF를 복사하지 않습니다.
- 1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920). 중앙 기준 cover 방식으로 이미지를 자릅니다. 투명 PNG의 투명도를 유지합니다.
- 한글·영문·이모지 문구, 글자 크기·색상·가로/세로 위치·그림자. 긴 문구는 자소/이모지 묶음 단위로 줄바꿈합니다. 영역 밖 문구는 경고합니다. 경고가 있는 상태로 저장하면 밖의 문구는 잘릴 수 있습니다.
- 미리보기 Canvas 자체를 PNG로 내보내므로 이미지 배치·글자·줄바꿈이 동일합니다.
- IndexedDB에 최대 30개 템플릿을 저장합니다. 이름과 이미지 및 편집 상태를 함께 보존합니다. 저장 성공 이후에만 화면의 목록을 교체합니다.
- JSON version 1, 최대 50MB. 전체 데이터를 먼저 검증하고 한 번의 트랜잭션으로 추가합니다. 중복 ID 충돌을 막기 위해 가져온 항목에는 새 ID를 부여합니다. 잘못된 JSON은 기존 목록과 편집 상태를 변경하지 않습니다.
- 저장 데이터는 브라우저와 사이트 주소별로 분리됩니다. 시크릿 창 종료 또는 브라우저 데이터 삭제 시 사라질 수 있으니 JSON으로 백업하세요.
- 업로드 이미지는 서버에 전송하지 않습니다. 사용자가 다운로드한 JSON에는 이미지가 포함되므로 공유 전에 내용을 확인하세요.

## 검사

`evidence/test-results.json`: 실제 Edge 브라우저 검사 결과. `evidence/newlines-before.json`, `evidence/newlines-after.json`: 동일 입력의 결함 수정 기록. `qa/test.cjs`와 `qa/newlines.cjs`: 재현 스크립트입니다. Playwright와 Microsoft Edge가 필요하며 경로는 환경에 맞게 수정하세요.

WebMCP configure_card는 지원 브라우저에서만 등록하며 일반 편집에는 영향을 주지 않습니다. 이 환경에 네이티브 WebMCP 실행 컨텍스트가 없어 해당 API의 실제 등록 검증은 하지 못했습니다.

## 이미지 사용 근거

완성 이미지 `card-1x1.png`, `card-4x5.png`, `card-9x16.png`의 배경은 이 프로젝트의 Canvas 코드가 생성한 그라데이션과 원형 선입니다. 외부 사진/이미지 소스는 사용하지 않았습니다. 문구와 배치는 AI가 과제용 예시로 구성했습니다. 학생 본인이 직접 촬영·제작한 사진이라고 주장하지 않습니다.

공개 파일에는 업로드한 개인 사진, 개인정보, API 비밀값을 포함하지 않습니다. 완성 PNG의 메타데이터 검사 결과는 검사 보고서를 참고하세요.
